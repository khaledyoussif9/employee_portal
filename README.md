# Employee Portal

بوابة موظفين مبنية باستخدام Flask وSQL Server لعرض البيانات الإدارية وشريط المرتب وسجل الأجور، مع واجهة عربية ودعم إنشاء ملفات PDF.

## التشغيل

1. ثبّت Python 3.11 أو أحدث.
2. أنشئ بيئة افتراضية وثبّت الحزم من `requirements.txt`.
3. انسخ `.env.example` إلى `.env` واضبط بيانات SQL Server وباقي المتغيرات.
4. شغّل التطبيق باستخدام `python app.py` للتطوير أو Gunicorn في بيئة الإنتاج.

## ملفات المشروع

- `app.py`: واجهة Flask ومسارات API.
- `db.py`: الاتصال بقاعدة SQL Server.
- `employee_portal.html`: واجهة الويب.
- `pdf_generator.py`: إنشاء شريط المرتب وسجل الأجور بصيغة PDF.

لا ترفع ملف `.env` أو كلمات المرور أو ملفات الموظفين إلى المستودع.
